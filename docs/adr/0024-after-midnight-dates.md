# ADR 0024: Hours after midnight name their calendar date

- **Status:** Accepted
- **Date:** 2026-09-28
- **Owner:** host
- **Replaces:** `after-midnight-dates` (former decision entries)

## Context

Hour ranges may cross midnight (WPA-44); the grid shows those hours under the evening's column.

## Decision

An hour or a run that starts after midnight names its calendar date wherever it is written out: "Ustalone", the best time and a tapped hour's details ("Sobota 19.10, 1–3"). The grid keeps it under the evening's column (WPA-21; WPA-43 for the set time).

## Consequences

A new place that writes an hour out with the column's date names the wrong day.
