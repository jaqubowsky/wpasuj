# LinkCard

What a group chat unfurls for a poll link: who asks, the plan in display type, and "wpasuj.pl". It shows people what their friends will see.

- `asker` ("Kuba pyta, kiedy możesz"), `title`, `tone` and an optional `note` beside the address.
- `ink` head with `on-dark-muted` asker, or `coral` head with `ink` text (5.3:1); the address row on `surface` in `muted`.
- `radius-card`, `shadow-poster`, full width up to 420px. It is a figure named by its title.
