# Stepper

Picks a whole number in a small range by taps: the hours of a custom range ("od", "do"). Used instead of a dropdown.

- The consumer provides the value, the bounds and the label; − and + are `size-target` buttons with labels for screen readers ("Wcześniej", "Później").
- At a bound the button is disabled and `muted`.
- The value is set in `day-number` so it reads at a glance.
