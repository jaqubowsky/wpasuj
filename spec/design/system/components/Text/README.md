# Text

The type styles as the product uses them; every piece of text on a screen is one of these, never an ad hoc size.

- Display styles (`wordmark`, `title`, `best-time`, `day-number`, `heading`) are Bricolage Grotesque; text styles (`body`, `chip`, `button`, `meta`) are Onest.
- The consumer provides the words and picks the style by role, not by size: a poll title is `title` even when short.
- `meta` is always `muted`; everything else is `ink` on light grounds and white on `ink`.
- Numbers that change (counts, hours, dates) use tabular figures.
