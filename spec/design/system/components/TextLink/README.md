# TextLink

A link in words, for the way out of a page: "Zrób własną ankietę" under a poll and on the error page.

- `ink`, Onest 700 at `text-base`, a 2px underline 4px below the text, as the prototype's footer link (ADR 0035). It stays `size-target` tall.
- The consumer provides `href` and the words; a link that should look like the page's main action is a ledge button instead.
