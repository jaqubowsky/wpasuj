# WaveEdge

A 28px wavy edge between a paper section and a full-bleed `ink` or `coral` section, drawn full width.

- `tone`: `ink` or `coral`, the colour of the section it borders.
- `side`: `top` sits above that section (the wave rises out of paper), `bottom` sits below it (the colour ends in a wave).
- Decorative, hidden from assistive technology; it never carries meaning.
